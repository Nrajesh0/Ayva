Encrypted Notes & Secret Vault

Zero-Leakage Architecture • Anti-Screenshot (FLAG_SECURE) Protected
Argon2id + AES-256-GCM BIP-39 Mnemonic Recovery

Ayva features a modular Notesnook-grade block editor designed for high-focus writing, structured data, and private journaling. Why no screenshots? Ayva actively applies WindowManager.LayoutParams.FLAG_SECURE to sensitive surfaces—intercepting OS screenshot capture, screen recording, and system app switcher thumbnails at the Linux display server boundary.

🧱 Notesnook Block Engine Modular blocks for Headings, Checklists, Syntax-highlighted Code (Kotlin, Python, Java), LaTeX Math Formulas (\(E = mc^2\)), and Callout alert boxes (Note, Warning, Tip, Success).
📊 Interactive Tables Native multi-column spreadsheet tables with dynamic row/column addition, column width dragging, and structured markdown serialization.
🎨 Vector Sketch Canvas Freehand sketching with Pen, Brush, Highlighter, Eraser, stroke weight controls, and rule/grid overlays embedded directly into notes.
🎙️ Encrypted Audio Memos Built-in audio memo recording with real-time amplitude waveforms and playback scrubbing, stored in encrypted local storage.
📄 Word (.docx) & Print PDF Native export to Microsoft Word .docx (clean OpenXML) and print-ready PDF with automatic Table of Contents and document reading statistics.
🔐 Hardware Keystore & Recovery Protected by 6-digit PIN with native Argon2id KDF, AES-256-GCM Keystore hardware encryption, rate-limiting escalation, and 12-word BIP-39 phrase disaster recovery.
