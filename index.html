BAL-Proof Direct Window Overlay

Android 14, 15, and 16 introduced strict Background Activity Launch (BAL) restrictions that break conventional app lockers that rely on startActivity. RuN renders its blocker via direct system window management (WindowManager.addView with TYPE_APPLICATION_OVERLAY) guaranteeing instant, unbypassable interception.

Frequently Asked Questions

RuN operates as a local Android accessibility / usage-stats overlay service. It monitors foreground package events entirely locally on your processor. When a restricted app is launched, RuN renders a secure system window overlay directly via WindowManager in less than 15 milliseconds, without ever querying an external server.
Modern Android releases heavily restrict Background Activity Launches (BAL), causing traditional app blockers (which try to launch an activity screen over the target app) to fail with security exceptions. RuN uses the direct WindowManager.addView overlay method (TYPE_APPLICATION_OVERLAY), which bypasses BAL constraints and works smoothly across all modern Android versions.
RuN includes device administrator protections, biometric authentication locks, and sticky foreground service execution with auto-restart receivers, preventing circumvention during active focus sessions.
