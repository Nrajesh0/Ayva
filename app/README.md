# RuN

RuN is a privacy-first, fully offline App Locker & Focus Tracker.

## Architecture & Privacy
- **Privacy-First**: Zero trackers or analytics. Completely offline architecture.
- **Minimal External Dependencies**: Self-contained and secure.
- **Fastlane Metadata Included**: Available in `fastlane/metadata/android/en-US/`

### Build Instructions
To build the application locally:
```bash
./gradlew assembleRelease
```
